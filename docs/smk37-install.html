SMK-37 Elite Installer

P-Vox for the M-VAVE SMK-37 Elite, package identity SMK-37 Elite_900. Flash with the official one-click page from the v1.2-smk37-900 release. Use desktop Chrome or Edge. No drivers and no terminal.

1
Download the official flash page

Get Polivoks-Flash-SMK37-Elite-900-v1.2.html from the GitHub release. That file already contains the complete package, so you can open it locally with no server.

2
Connect your SMK-37 Elite

Plug it in by USB and keep it powered for the whole flash. Open the downloaded HTML page in desktop Chrome or Edge.

3
Flash

Tick the confirmation box, press the flash button, and allow MIDI SysEx when the browser asks. Wait until the page reports that the package was transferred and the device identity is SMK-37 Elite_900. Do not unplug mid-flash.
