Polivokz by Hans Volt

SMK-37 Elite Installer

Flash the Polivoks firmware to your SMK-37 Elite. Chrome or Edge required. Web MIDI only — no drivers, no terminal.

1
Connect your SMK-37 Elite

Plug it in via USB. It should appear as an MIDI device. Keep it powered during the whole flash.

2
Allow MIDI access

When the browser prompts, click Allow. If it never prompted, check that the site is served over HTTPS and that no other app is holding the MIDI port.

3
Flash

The page downloads the firmware package from the GitHub release, then sends it to the unit over SysEx in chunks with verify-back. Takes a couple of minutes. Do not unplug mid-flash.

Firmware: Polivoks SMK-37 Elite PlayGen, tag v1.1-smk37-900. Source and release: github.com/HanzVolt/P-Vox. License: GPL-3.0. If the flash fails, power-cycle the unit and retry — the loader keeps a fallback path. This page does not host the firmware binary; it pulls it live from the release so you always get the current build.
